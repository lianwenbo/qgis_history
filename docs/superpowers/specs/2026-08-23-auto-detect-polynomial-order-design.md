# GCP 逆向映射多项式阶数自动识别设计

日期：2026-08-23
状态：已批准实施

## 背景

QGIS 地理配准器将最近一次使用的变换方法保存在全局用户配置中，而不是每幅地图的
`.jpg.points` 文件中。不过，points 文件包含 QGIS 在所选变换方法下为每个启用的
GCP 计算出的标量残差。

当前 `boundaries/generate_chgis_labelme.py` 中的逆向映射始终拟合二阶多项式，
因此无法复现使用三阶多项式校准的地图。对 `04-25宋` 的相同 GCP 分别进行拟合后
可以确认，其 QGIS 已保存残差向量匹配三阶多项式，而不是二阶多项式。

## 决策

不增加 sidecar 元数据。执行逆向映射时，同时拟合二阶和三阶的“地理坐标到像素坐标”
模型，并分别将模型的逐 GCP 残差向量与 QGIS 保存的残差向量比较。仅当恰好有一个
阶数匹配时才继续执行。

已保存残差只作为识别 QGIS 变换方法的证据，不作为通用模型优选分数。

## 范围

本次变更涉及：

- `boundaries/generate_chgis_labelme.py`；
- `boundaries/generate_donghan_labelme.py`；
- 上述脚本使用的共享多项式拟合逻辑；
- 针对拟合、识别和错误处理的专项自动化测试。

边界模型推理不做修改，因为它直接读取原始 JPG 像素，不使用 GCP 变换。

## 输入约定

自动识别要求使用 QGIS 保存的 `.jpg.points` 文件，且包含：

```text
mapX,mapY,sourceX,sourceY,enable,dX,dY,residual
```

只有 `enable == 1` 的行参与计算。

脚本初始生成、残差全部为零的 `.points` 文件不包含足够信息，无法恢复 QGIS 使用的
变换阶数。除非调用方明确指定阶数，否则自动识别必须拒绝此类文件。

## 多项式模型

引入支持指定阶数的“地理坐标到像素坐标”多项式模型。

对于阶数 `d`，设计矩阵包含所有满足 `i + j <= d` 的二元项 `x^i y^j`。

- 二阶包含 6 项，至少需要 6 个启用的 GCP。
- 三阶包含 10 项，至少需要 10 个启用的 GCP。

拟合前对经度和纬度进行归一化。模型通过最小二乘法同时拟合两个像素坐标，并拒绝
秩不足的设计矩阵。

模型对外提供：

- 多项式阶数；
- 启用的 GCP 数量；
- 逐 GCP 残差向量；
- 平均残差；
- 最大残差；
- 地理坐标到像素坐标的变换。

## 识别算法

自动识别分别评估二阶和三阶：

1. 读取启用的 GCP 以及 QGIS 保存的标量 `residual` 值。
2. 如果所有已保存残差在绝对阈值 `1e-9` 下均可视为零，则拒绝自动识别。
3. 对 GCP 数量满足要求的每个候选阶数进行拟合。
4. 计算该候选模型在每个启用 GCP 上的标量残差。
5. 按原始行顺序，将候选残差向量与 QGIS 保存的残差向量比较。
6. 当逐元素绝对差的最大值不超过 `0.01px` 时，认定该候选阶数匹配。
7. 仅当恰好有一个候选阶数匹配时才选择该阶数。

失败场景：

- 没有匹配：文件可能使用了不支持的变换、包含过期残差，或在 QGIS 外被修改。
- 多个匹配：当前 GCP 几何无法唯一确定阶数。
- GCP 数量不足或矩阵秩不足：无法评估对应候选阶数。

所有失败场景都必须在写入任何输出文件前停止。

## 显式覆盖

两个逆向生成 CLI 均增加：

```text
--polynomial-order {2,3}
```

默认使用自动识别。显式传入阶数时跳过残差向量匹配，但仍校验 GCP 数量、矩阵秩和
拟合残差摘要。

显式覆盖用于：

- 残差为零的脚本生成 `.points` 文件；
- 已知残差不可用的 QGIS 文件；
- 诊断无法支持或无法唯一识别的文件。

所选阶数必须在输出中醒目展示，避免将显式覆盖误认为自动识别结果。

## 数据流

自动模式：

```text
.jpg.points
  -> 解析启用的 GCP 和已保存残差
  -> 拟合二阶和三阶
  -> 匹配残差特征
  -> 选择唯一阶数
  -> 拟合并使用“地理坐标到像素坐标”逆向模型
  -> 将矢量几何映射到原始图片像素
  -> 写入 LabelMe 和预览输出
```

显式模式使用调用方提供的阶数替代残差特征匹配步骤。

## 来源记录与输出

生成的 LabelMe 来源信息记录：

```text
transform=polynomial_<order>_inverse_gcp
transform_order_source=detected_qgis_residuals
```

显式覆盖时记录：

```text
transform_order_source=explicit_cli
```

命令摘要包含：

- 选定的多项式阶数；
- 阶数来源（`detected_qgis_residuals` 或 `explicit_cli`）；
- 启用的 GCP 数量；
- 拟合平均残差和最大残差；
- 自动模式下残差特征的最大差值。

## 兼容性

- 对于残差能唯一匹配二阶或三阶的 QGIS points 文件，现有调用不传
  `--polynomial-order` 也可以继续工作。
- 二阶项和归一化方法保持不变，因此现有二阶几何结果在浮点误差范围内不变。
- 残差为零的原始生成 points 文件将明确失败，不再被静默视为二阶。
- 不支持的 QGIS 变换将明确失败，不再生成表面合理但实际错误的逆向映射。

## 错误信息

错误信息需要明确指出受影响的 points 文件，并给出修复方式：

- 在 QGIS 中选择预期变换后重新保存 GCP points；
- 检查 QGIS 是否使用了当前不支持的变换方法；
- 当阶数已经通过其他方式确认时，使用 `--polynomial-order 2` 或
  `--polynomial-order 3` 重新运行。

脚本必须在创建或覆盖 LabelMe 和预览输出前完成校验和阶数选择。

## 测试

单元测试覆盖：

- 二阶和三阶多项式项的生成；
- 最小 GCP 数量和矩阵秩校验；
- 精确复现现有二阶逆向坐标；
- 根据已保存残差识别二阶；
- 使用 `04-25宋` 的残差行为识别三阶；
- 拒绝残差全部为零的文件；
- 拒绝没有阶数匹配的文件；
- 拒绝多个阶数同时匹配的文件；
- 显式阶数覆盖。

集成测试覆盖：

- 自动识别二阶后生成 CHGIS LabelMe；
- 自动识别三阶后创建逆向模型；
- 自动识别模式和显式模式的来源字段；
- 识别失败时不修改已有输出。

## 验收标准

- `04-25宋.jpg.points` 能被自动识别为三阶。
- 现有区域图的 QGIS points 残差匹配二阶时，能被自动识别为二阶。
- 逆向生成不能静默选择不匹配的阶数。
- 显式覆盖支持没有可用 QGIS 残差的文件。
- 生成的来源信息同时记录所选阶数及其选择方式。
- 现有二阶逆向坐标在 `1e-6px` 范围内保持不变。
